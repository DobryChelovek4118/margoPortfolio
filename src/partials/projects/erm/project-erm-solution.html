Решение

Для начала было проведено глубинное интервью с 12 пользователями системы и собрана обратная связь.

Основные моменты, которых не хватало в старом варианте:

  • Не было удобной фильтрации по колонкам
  • Не все значения показывались корректно
  • Нужно было разделять документы на актуальные и архивные
  • Не хватало админ-функционала
  • Не хватало нескольких разделов для удобного управления
