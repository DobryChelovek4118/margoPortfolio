Аудитория

B2C, пользователи, которые хотят подключить или расширить интернет-тариф

Цель

Сделать единый шаблон для всех сайтов провайдеров, чтобы сократить время разработки нового сайта и ускорить внедрение новых фич на существующие сайты

Задачи

  • Сделать единый шаблон, подходящий под стиль большинства сайтов
  • Настроить шаблон таким образом, чтобы изменения по стилю и новым функциям вносились минимальными усилиями для разработчиков
