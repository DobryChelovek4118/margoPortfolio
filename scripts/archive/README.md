# Архив скриптов

Разовые миграции (уже применены). Не запускать на текущем репозитории без необходимости.

- `migrate-assets.mjs` — перенос и переименование медиа
- `replace-img-paths-webp.mjs` — замена `.png`/`.jpg` на `.webp` в путях
- `to-webp-only.mjs` — конвертация растра в WebP и удаление PNG/JPG

Актуальные скрипты — в `scripts/` и `npm run`.
